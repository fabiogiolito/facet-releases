# Facet

Test builds of Facet for macOS (Apple Silicon, macOS 13 or newer).

**[Download the latest version](https://github.com/fabiogiolito/facet-releases/releases/latest)**: get `Facet-<version>-arm64.dmg` under Assets, open it and drag Facet into Applications.

Facet checks this page for updates when it opens and offers new versions with their release notes; nothing to download again by hand.
